# Guardian - Hard

A Hack The Box machine writeup documenting web application security assessment, vulnerability exploitation, lateral movement, and Linux privilege escalation.

## Machine Information

| Category | Details |
|---|---|
| Platform | Hack The Box |
| Machine | Guardian |
| Difficulty | Hard |
| Operating System | Linux |

## Key Findings

- Default Credentials
- Insecure Direct Object Reference (IDOR)
- Hardcoded Database Credentials
- Stored Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Local File Inclusion (LFI) to Remote Code Execution
- Weak Password Hashing
- Insecure Sudo Configuration
- Apache Configuration Injection

## Technical Areas

- Web Application Penetration Testing
